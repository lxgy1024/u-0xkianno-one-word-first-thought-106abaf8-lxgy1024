## The word

**petrichor** — the scent of rain falling on dry earth.

One word, the first that came to mind: vivid, specific, and surprising, the kind of word a reader would not have guessed.

## How it works

`main.ts` (Node 22) writes the single word to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). The output is exactly 9 characters, no trailing newline, so it is byte-identical on every run.

## Run it

```sh
node main.ts
```
